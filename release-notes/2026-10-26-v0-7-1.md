**Maintenance release.** Security and reliability improvements.

<!-- truncate -->

## Security

- Updated the platform to the latest Node.js security release.
- Strengthened protection of the sign-in page.
- Updated third-party components with known vulnerabilities.

## Fixed

- Submitting two overlapping leave requests at the same moment now shows a clear message instead of an error.
- Leave balances are always returned correctly when a request is rejected or cancelled, even if the leave type was changed in the meantime.
- Managers are only asked to approve leave they are actually allowed to approve, and HR keeps seeing requests they can still decide.
- Improved the stability of real-time notifications when the connection to the database is interrupted.
