# Leave Policies

Leave settings are under the **Master Cuti** (Leave Settings) menu.

## Leave types

**Master Cuti › Jenis Cuti** (Leave Types). For each type you can set:

| Setting | Effect |
| --- | --- |
| Annual allowance | Days granted automatically every year (for example, 12 days of annual leave) |
| Deducts balance | Whether requests use up the balance |
| Paid | Whether the leave is paid |
| Supporting document | Required, or required only above a number of days |
| Maximum days per request | Longest single request allowed |
| Minimum notice | How many days in advance it must be requested |
| Gender | Restrict the type, for example maternity leave |
| Exempt from department limit | For unplanned leave such as sickness, bereavement, or maternity |

A leave type that has already been used can't be deleted; deactivate it instead.

## Holidays

**Master Cuti › Hari Libur** (Holidays). Public holidays and collective leave are excluded from leave duration and from attendance.

## Department leave limit

On the **Department** page, set the maximum number of employees who may be on leave on the same day. Leave the field empty for no limit.

- Only approved leave counts toward the limit.
- Employees can't request dates that are already full, and approvals that would exceed the limit are blocked.
- Exempt leave types (such as sick leave) are never blocked, but still count toward the limit.
- HR can approve above the limit in exceptional cases by writing a reason; the override is recorded.

## Balances

Balances are kept as a history of changes rather than a single number, so every day can be traced: the annual allowance, days reserved by pending requests, days used by approved leave, and days returned when requests are rejected or cancelled.

To correct a balance, use **Master Cuti › Penyesuaian Saldo** (Balance Adjustment) with a note explaining why. A correction can't make a balance negative.
