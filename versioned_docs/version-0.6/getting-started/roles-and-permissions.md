# Roles and Permissions

As in later versions, there are only two roles, `admin` and `employee`. Administrators bypass every permission check. Every other capability is a **feature** granted to a **position**, for example `leave.approve_team`, `leave.approve_all`, `employee.create`, or `organization.manage`.

`system.view_api_docs`, which opens the in-app API documentation, was introduced in 0.6.0.

See the [latest feature catalog](pathname:///docs/getting-started/roles-and-permissions) for the full list.
