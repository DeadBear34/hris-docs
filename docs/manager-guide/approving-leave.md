# Approving Leave

Go to **Persetujuan Cuti** (Leave Approvals). You receive a notification whenever a request needs your decision.

## Which requests you see

| You are… | You see |
| --- | --- |
| A manager | Requests from your direct reports |
| HR with approve-all access | Every request except your own |

HRIS assigns each request to the requester's line manager automatically. If the organization changes while a request is pending, the request moves to the new manager and both of you are notified.

## Review a request

Open a request to see:

- the leave type, dates, number of working days, and reason;
- supporting documents, if any;
- **colleagues on leave**: other people in the same department whose leave overlaps these dates, so you can judge team coverage.

## Approve or reject

Select **Setujui** (Approve) or **Tolak** (Reject) and add an optional note for the employee. The employee is notified immediately.

- **Supporting documents.** Some leave types can't be approved until the required document has been uploaded.
- **Department limit.** If approving would exceed the department's limit of people on leave at the same time, approval is blocked and the full dates are shown. HR can still approve in exceptional cases by giving a written reason; the override is recorded.
- **Your own leave.** You can never approve or reject your own request; it goes to your own manager.
- **Changed in the meantime.** If the employee cancels while you are deciding, you'll be asked to reload.
